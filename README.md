# grsm-landscape-genetics
Landscape genetics of feral swine in Great Smoky Mountain 
Matt DeSaix

 - `*.Rmd` files contain the majority of the analyses completed for this project
 
 - `gsmnp-cv.ipynb` is the Jupyter notebook for running the FEEMS analysis
 
 - `./scripts/hpc/*` contains the scripts for running some of the analyses on an HPC with Slurm
